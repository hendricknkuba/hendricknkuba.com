# U-Haul One Year Images

Image assets for the game-style U-Haul one-year story page.

Recommended files:

- `opening-scene.webp` - Opening visual or fallback game scene.
- `early-days.webp` - Early work memory image.
- `work-action.webp` - Work/action memory image.
- `team-01.webp` through `team-06.webp` - Team memory-card images, if permission is confirmed.
- `final-road.webp` - Final scene visual.

Guidelines:

- Use `.webp` where possible.
- Avoid internal systems, customer details, license plates, and private workplace information.
- Confirm permission before using identifiable team photos.
- Keep large hero images under reasonable web size before launch.
