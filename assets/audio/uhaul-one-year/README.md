# U-Haul One Year Audio

Audio assets for the game-style U-Haul one-year story page.

Recommended files:

- `background.mp3` or `background.ogg` - Reflective background music.

Guidelines:

- Use music that is licensed for public portfolio use.
- Keep the page muted by default.
- Provide a visible keyboard-accessible sound toggle.
- Do not rely on autoplay with sound because browsers usually block it.
